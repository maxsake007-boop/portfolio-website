# Папка для ваших файлов и ассетов (User Assets)

Сюда вы можете скидывать любые файлы:
- 🖼️ **Изображения**: фото проектов, аватарки, логотипы, фоны (.png, .jpg, .webp, .svg)
- 📄 **Документы**: резюме (CV), сертификаты (.pdf, .docx)
- 🎬 **Медиа**: видео, анимации, аудио
- 📝 **Текстовые материалы**: описания проектов, списки навыков, контакты

После добавления файлов просто напишите мне в чат, например:
> *"Я закинул аватарку avatar.png и скриншоты проектов в папку user-assets, используй их в блоках Hero и Projects"*

Я сразу подхвачу их и подключу в нужные компоненты!
